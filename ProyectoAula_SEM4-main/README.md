Este repositorio contiene el proyecto final del cuarto semestre, una aplicación web diseñada para la gestión de inventario y pedidos. La aplicación permitirá registrar y administrar el stock de productos, así como gestionar los pedidos de manera eficiente. 

💻 Tecnologías y Herramientas
Para el desarrollo del frontend de la aplicación, usaremos HTML y CSS para construir la interfaz de usuario y darle estilo. Para el backend, se empleará el framework Spring Boot para manejar la lógica del negocio. Toda la información del inventario y los pedidos se almacenará en una base de datos MySQL. Finalmente, para la colaboración y el control de versiones, utilizaremos Git y GitHub.

La combinación de estas tecnologías nos permitirá crear una aplicación completa y funcional para nuestro proyecto.
